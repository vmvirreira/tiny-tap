# Tiny Tap

Ten touch-first mini-games for babies and toddlers, organized from 6 months to 2+ years. The experience is ad-free, score-free, responsive, and designed for shared play with a grown-up.

## Games

- Color Splash and Peekaboo (6+ months)
- Animal Hello and Bubble Pop (9+ months)
- Finger Paint and Happy Notes (12+ months)
- Catch the Star and Shape Homes (18+ months)
- Apple Basket and Copy the Beat (2+ years)

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown in the terminal.

## Build

```bash
npm run build
```

The static site is written to `dist/client` and can be deployed to Vercel.
